## Dynamic/native items that are NOT visual-asset generation tasks

Do not create raster images for:
- text, labels, localized copy;
- numbers, timers, prices, balances, reward amounts;
- batch quantities/colors;
- BoardRenderer pixel cells;
- Gift Meter/Bot Parts/Heart live progress values;
- responsive panel layout when native Godot styling already owns it;
- rail routing/pathfinding geometry or gameplay truth;
- player name/level;
- touch/pressed/disabled behavior;
- economy or gameplay state.

## Collection-card rule

The 135 card slots above are file destinations, not invented identities.
Before each Collection card is produced, inspect its corresponding owner reference image. If the card identity can be cleanly extracted from the approved 3×3 set composite, crop/extract and clean it rather than re-imagining it. If generation is necessary, preserve the exact subject identity/concept seen in the owner reference. Never invent a new character or rename a card.
