# SB-M37-002 — Current level

Status: IMPLEMENTED
Requirement: one authoritative service owns current progression level; reject
invalid <=0 state; consumers read, do not mutate internals.

## Production owner
`LevelProgressionService`:
- `current_level()` read accessor (starts at 1);
- frontier advances only inside `record_win` for a new first-clear of the
  current frontier level;
- `debug_set_current_level(n)` rejects n<1 (test/dev seam only, non-shipping).
- No public setter mutates `_current_level` arbitrarily from UI.

## Direct tests
`_current_level_and_frontier` — starts at 1; win advances to 2; debug set
rejects 0, accepts 5.

## Failure condition
Frontier settable to <=0 or advanced without a first-clear.

## Actual
PASS.
