# SB-M37-004 — Replay

Status: IMPLEMENTED
Requirement: replay may load a completed level without changing the frontier or
first-clear truth. Replay completion must not re-advance progression.

## Production owner
`record_win(level_number, is_replay=true)` short-circuits and returns false
before touching `_completed` or `_current_level`.

## Direct tests
`_replay_non_advancing`:
- replay win returns false;
- frontier unchanged;
- completed_count unchanged;
- replay loss is a no-op (no `record_win` call), frontier stable.

## Failure condition
Replay win advances the frontier or fires first-clear reward truth.

## Actual
PASS.
