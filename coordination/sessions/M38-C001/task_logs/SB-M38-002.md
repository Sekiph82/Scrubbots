Status: IMPLEMENTED

replay wins, duplicate terminal callbacks, old-level callbacks, non-progression
wins do not.

- `is_replay=true` -> no increment;
- `_processed_levels` set makes duplicate/old-level WON a no-op;
- invalid level_number (<1) rejected.
