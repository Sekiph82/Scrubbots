# SB-M38-013 — Gift Meter source isolation

Status: IMPLEMENTED
Requirement: only streak-bonus SB amount is forwarded to GiftMeterService. Base
first-clear SB, Daily, Gift rewards, exchange, refunds, arbitrary wallet grants
must not call the streak feed.

## Production owner
`WinStreakService` calls `_gift.add_streak_sb("gift:L<n>", sb)` with ONLY the
streak-bonus SB. No other code path calls `add_streak_sb`. Base/other grants go
through `RewardGrantService.grant` which does not touch the gift meter.

## Direct tests
`_gift_meter_source_isolation` — streak SB (1+5+10=16) feeds gift meter; a
subsequent direct base-SB grant leaves gift total unchanged.

## Actual
PASS. Full milestone reward payout (booster/card) is M39 behavior on top of the
queue; M38 provides only the minimal canonical seam.
