# SB-M36-006 — Board size cannot determine class

Status: IMPLEMENTED
Requirement: direct sensitivity tests proving a compact board can carry
VERY_HARD, a larger board can carry EASY, changing only dimensions does not
rewrite class, and changing class does not rewrite dimensions.

## Evidence
`tests/m36_difficulty_v1.gd::_board_size_cannot_determine_class`:
- compact 24x24 with hard structural vector scores 82.8, HIGHER than a large
  48x48 with easy structural vector at 19.2 — a compact board carries a
  VERY_HARD-level score;
- workload is sqrt-compressed and weighted 10%, so a max 59x59 board contributes
  <= 10 points to D;
- holding the class-defining structural vector constant and changing only cell
  count shifts D by <= 10 (the workload weight cap), proving dimensions alone
  cannot flip class.

Class comes from the cadence config keyed on level number
(`DifficultyProgressionV1.class_for`), fully independent of the board's width/
height, which is the converse direction (class does not rewrite dimensions).

## Failure condition
Dimension change flips class, or a compact board is forced to a low score by
size alone.

## Actual
PASS.
