# SB-M34-001 — Platform API research

Status: IMPLEMENTED
Prompt: `coordination/sessions/M34-C001/CHATGPT_PROMPT_V01.md`
Criteria: `coordination/sessions/M34-C001/CHATGPT_AUDIT_CRITERIA_V01.md`

## Requirement
Record the Godot 4.7.2 built-in vibration/haptic API and its per-platform
limits. State what is directly testable headless versus device-only.

## Deliverable
`docs/12_HAPTICS_PLATFORM_RESEARCH.md`. Covers:
- built-in seam `Input.vibrate_handheld(ms)`
- Android/iOS/desktop/headless behavior
- rejection of gamepad seam for V1
- what is headless-testable vs owner/device-gated
- no paid dependency / no gdextension

## Direct tests
Headless invocation of `Input.vibrate_handheld` on desktop is a documented no-op
so cannot be asserted "as felt"; instead we exercise the wrapping
`HapticsController._platform_vibrate` through a test sink in
`tests/m34_haptics_runtime.gd`, which counts call count and duration. This
proves the control path without depending on human perception.

## Actual result
Doc written. All controller/burst/latch tests pass (see M34 test log).

## Known limitation
Real per-device vibration feel is not verifiable headless — that is SB-M34-006.
