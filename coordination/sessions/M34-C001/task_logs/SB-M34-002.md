# SB-M34-002 — Cleaning haptic

Status: IMPLEMENTED
Requirement: cleaning haptic must observe only the authoritative committed
`CompleteClearingLoop.authenticated_clear` seam. Failed/rolled-back clears emit
no request. Gameplay clear must never wait on haptics.

## Production owner / API
`scripts/haptics/haptics_controller.gd`
- observer method `_on_authenticated_clear(owner_id, target_index, color_id, agent)`
- delegates to `request_cleaning()`

## Direct tests
`tests/m34_haptics_runtime.gd::_toggle_and_burst`:
- 20 direct `request_cleaning()` calls counted as 20 requests.
- Toggle OFF: 20 requests -> 0 played, 20 suppressed, 0 platform calls.
- Toggle ON: platform call count strictly equals played count.

## Expected result
`played` never exceeds throttle budget; `suppressed` accounts for the rest.

## Failure condition
`played` > cap OR platform sink observed a call while OFF.

## Actual
PASS. Burst limited to <=2 played within the same tick window (throttle 60ms).

## Notes
Haptics is a pure observer of the M20/M30 event contract; failed dispatch/rolled
back clears never reach `authenticated_clear` and so never reach the sink.
