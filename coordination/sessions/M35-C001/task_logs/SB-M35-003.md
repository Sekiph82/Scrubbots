# SB-M35-003 — Stable ordering

Status: IMPLEMENTED
Requirement: catalog order is deterministic and explicit. Duplicate order
positions or reliance on lexical/OS order are invalid.

## Production owner
`level_catalog.gd`:
- integer `order` field required per entry;
- duplicate order fails closed;
- `_compare_entries` sorts by `order`, then id, so runs are deterministic even
  across filesystems.

## Direct tests
`tests/m35_level_catalog.gd::_duplicate_order` — duplicate order fails closed.

## Failure condition
Non-integer order, missing order, or duplicate order.
