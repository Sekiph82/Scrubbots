# SB-M35-008 — Missing-file detection

Status: IMPLEMENTED
Requirement: fail closed when a referenced production level/metadata path is
missing or unreadable.

## Production owner
`level_catalog.gd::load_manifest`:
- `FileAccess.file_exists(level_path)` gates every entry.
- Metadata file is optional but, if referenced, must exist.
- `LevelLoader.load_from_path` failures propagate into
  `LevelCatalogValidationResult.add_entry_error` keyed by the entry id.

## Direct tests
- `_missing_level_file` — phantom path fails closed.
- `_malformed_level_json` — malformed target level fails closed with structural
  diagnostic.

## Failure condition
Missing/unreadable file quietly skipped and catalog still surfaced as ok.

## Actual
PASS.
