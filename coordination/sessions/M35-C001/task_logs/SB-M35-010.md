# SB-M35-010 — Reject TEST fixture in production catalog

Status: IMPLEMENTED
Requirement: even if a TEST file is manually inserted into a catalog source,
validation must reject it based on the canonical difficulty field, not on
filename conventions.

## Production owner
`level_catalog.gd::load_manifest` uses
`DifficultyRules.TEST_DIFFICULTY == "TEST"` on the loaded `LevelData` and
fails the entry with `"TEST fixture rejected in production catalog"`. This
check runs BEFORE `ProductionLevelValidator` so the diagnostic is unambiguous.

## Direct tests
`tests/m35_level_catalog.gd::_test_fixture_insertion` — writes a synthetic
level with `"difficulty": "TEST"` and a filename that does NOT contain
`test_`, then references it from a synthetic manifest. Load fails closed.

## Failure condition
TEST-difficulty entry accepted by the catalog.

## Actual
PASS.
