# SB-M35-007 — Duplicate detection

Status: IMPLEMENTED
Requirement: detect duplicate ids, duplicate order keys, and duplicate path
aliases resolving to the same production level. Fail closed.

## Production owner
`level_catalog.gd::load_manifest` maintains `seen_ids`, `seen_orders`,
`seen_paths` dictionaries. Path aliases are normalized (`_normalize_path`
collapses `/./` segments) before comparison so a manually-inserted alias
cannot smuggle in as a "different" path.

## Direct tests
- `_duplicate_id`
- `_duplicate_order`
- `_path_alias_duplicate`

## Failure condition
Any duplicate silently accepted.

## Actual
PASS on all three cases.
