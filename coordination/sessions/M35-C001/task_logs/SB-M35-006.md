# SB-M35-006 — Preview

Status: IMPLEMENTED
Requirement: catalog provides a stable preview/reference field suitable for
later UI; missing preview has defined behavior. Do not fabricate art.

## Production owner
`LevelCatalogEntry.preview_path` + `preview_exists`:
- `preview_path` is a stable `res://` string (or empty).
- Missing preview does NOT invalidate the entry; `preview_exists=false` is
  surfaced to the caller. UI can render a placeholder without the catalog
  fabricating art.

## Direct tests
`_production_catalog_loads` asserts M21 `preview_exists=true` against the
existing PNG.

## Failure condition
Preview mandatory, or a missing preview crashes catalog load.
