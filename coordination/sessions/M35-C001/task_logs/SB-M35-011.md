# SB-M35-011 — Batch validation

Status: IMPLEMENTED
Requirement: deterministic batch validation over every catalog entry with
entry-specific failures + aggregate fail-closed verdict. One invalid entry
cannot silently vanish.

## Production owner
`level_catalog.gd::validate_all()` runs `LevelLoader` + TEST-guard +
`ProductionLevelValidator` on every currently-registered entry and returns a
fresh `LevelCatalogValidationResult`.
`LevelCatalogValidationResult` carries:
- `ok` aggregate flag,
- per-entry `entry_errors` dict keyed by id,
- top-level `errors` for manifest-scope diagnostics.

## Direct tests
`tests/m35_level_catalog.gd::_batch_validation_determinism` — repeated
`validate_all()` returns identical ok verdict; adversarial cases
(dup id / dup order / missing file / TEST / unknown difficulty / malformed)
all report entry-scoped diagnostics rather than dropping entries silently.

## Failure condition
Invalid entry dropped from result without a diagnostic.

## Actual
PASS.
