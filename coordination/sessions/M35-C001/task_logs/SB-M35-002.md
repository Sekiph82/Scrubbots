# SB-M35-002 — Stable IDs

Status: IMPLEMENTED
Requirement: unique stable id per production level; independent of filesystem
enumeration order, transient array position, or mutable display name.

## Production owner
`level_catalog.gd::load_manifest` enforces:
- id is required, non-empty (post `strip_edges`);
- id must equal the id inside the referenced `LevelData` (`level.id`), so the
  catalog id is not a free label but the same stable string surfaced by
  the level JSON;
- duplicate ids are rejected fail-closed.

## Direct tests
`tests/m35_level_catalog.gd::_duplicate_id` — duplicate id fails closed.

## Failure condition
Two entries with the same id, or empty id.

PASS.
