# SB-M35-004 — Difficulty

Status: IMPLEMENTED
Requirement: expose current player-facing difficulty class. Must not re-lock
obsolete class=dimension semantics. Must be compatible with owner-locked
Difficulty V1 and M36 migration.

## Production owner
`level_catalog.gd`:
- `LevelCatalogEntry.difficulty` is the verbatim `level.difficulty` token
  surfaced by `LevelData`.
- M35 does not enforce class=dimension semantics beyond the legacy structural
  `ProductionLevelValidator` boundary already required for M21 compatibility.
- Unknown difficulty tokens are rejected by `ProductionLevelValidator` and
  therefore fail closed at catalog load.

## Direct tests
`tests/m35_level_catalog.gd::_unknown_difficulty` — SUPER token fails closed.
`_production_catalog_loads` — M21 EASY surfaced verbatim.

## Failure condition
Unknown token accepted or class silently rewritten.

## Actual
PASS.

## Note
M36 owns the Difficulty V1 challenge-score / cadence read model on top of the
same difficulty tokens. M35 exposes the raw class only; it does not compute
Challenge Score.
