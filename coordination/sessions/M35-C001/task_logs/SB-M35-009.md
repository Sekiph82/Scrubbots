# SB-M35-009 — Production/test separation

Status: IMPLEMENTED
Requirement: production catalog must exclude engineering fixtures
(`test_3x2.json`, `test_40x40.json`, `test_50x50.json`, `test_59x59.json`).

## Approach
Two orthogonal defenses:
1. `data/levels/catalog/production_catalog_v1.json` is a hand-authored manifest
   listing only production entries. There is no broad directory scan; a
   fixture cannot leak into the catalog by being placed alongside a production
   file.
2. Even if a TEST file were manually referenced, `SB-M35-010` catches it via
   the canonical `difficulty=="TEST"` field.
